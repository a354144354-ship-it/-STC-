基于 stm32 的智能环境报警系统（freertos+裸机） 个人 
简介：实现环境温湿度采集、OLED 本地显示与远程控制的智能温控系统。硬件上自主搭建传感器与执行器电路并独立设计 PCB；软件以 DMA 循环 ADC 
采集 + 均值滤波提升采样精度，PWM 调节风扇、灯光、报警器输出，自定义串口数据包协议（帧头、数据帧、帧尾）保证可靠解析。系统分别开发 FreeRTOS 
与裸机两个版本以对比不同软件架构：FreeRTOS 版划分采集、显示、通信、控制多任务，使用信号量完成同步与数据传递，按优先级调度保障实时响应；
裸机版采用主循环 + 中断的前后台架构，DMA/中断完成 ADC 采集与串口收发，以状态机解析数据包，逻辑精简、资源占用低。系统支持手动/自动双模
式，可依据环境参数自动联动执行器，或由自研手机 APP 经 HC04 蓝牙模块与电脑上位机下发指令远程控制。
